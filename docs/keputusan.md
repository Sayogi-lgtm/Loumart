# Catatan Keputusan Proyek

## Ketentuan dari dosen

| Hal | Ketentuan |
|---|---|
| Penyimpanan data | Proyek harus menggunakan database, bukan file JSON. Tim memilih MariaDB. |
| Tampilan | Boleh menggunakan library CSS eksternal. Tim memilih Tailwind CSS melalui CDN, bukan Bootstrap. |
| Waktu pengerjaan | Boleh selesai lebih awal, tetapi tidak boleh melewati batas waktu. |
| Presentasi | Wajib mempresentasikan progres setiap minggu. |
| Laporan | Dibuat dalam file Word dengan kerangka mengikuti dokumen FSD (Functional Specification Document). |
| Tema | Kelompok bebas memilih dari lima tema yang disediakan. |

## Cara kerja database tim

- Setiap anggota menggunakan database MariaDB lokal.
- Struktur tabel dan data awal disamakan melalui berkas setup yang disimpan di GitHub.
- Kredensial dan data pribadi database tidak dimasukkan ke GitHub.
- Kerangka FSD untuk laporan akan dibahas nanti.

## Tema proyek

Tema kelompok sudah ditentukan: **aplikasi sistem pemesanan dan manajemen penjualan**, dengan nama **LouMart**.
